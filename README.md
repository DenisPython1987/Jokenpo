# Jogo de Jokenpô

Esse é um trabalho feito para a faculdade de Ciência da Computação.
Você escolhe um elementos (pedra, papel ou tesoura) nos radiobuttons e
clica em "jogar". O computador vai escolher entre uma das opções, comparar com a sua e
dar o resultado do jogo.
